# 开发 Harness Seed

## 环境与入口

需要 Git 与 Python 3.10 或以上；无第三方运行依赖。根目录维护规则和入口，`.agents/skills/` 维护十个方法入口及按需参考，`scripts/` 与 `tests/` 维护结构检查与回归测试。当前没有构建产物或业务服务。

先读取根 [AGENTS](../AGENTS.md) 及目标路径规则。修改文档布局先查 [文档约定](AGENTS.md)；修改 Skill 先确认触发边界、失败分支和引用消费者。方法不能描述不存在的工具、脚本或验证结果。

## 修改与交付

1. 检查分支、工作区和需求基线，保留无关修改。将目标写成可观察的验收条件。
2. 修改最近的事实或方法拥有者，同次修复入链、路由、来源映射和受影响测试。
3. 运行 [测试说明](testing.md) 的相关检查；新增门禁须证明有效输入通过、错误输入在真实入口失败。
4. 涉及初始化或跨会话承诺时，在临时副本运行实际 Agent 场景，不将演示业务写进模板。
5. 检查最终差异和秘密，以中文说明目的、实际验证与限制。提交、推送和发布遵循当前授权；本地通过不代表远端通过。

改编上游时保留 [许可](../THIRD_PARTY_NOTICES.md) 并同步 [来源映射](upstream-mapping.md)。派生项目初始化需要把本页替换为自身真实环境和工作流，而不是保留模板维护步骤。
