# 验证说明

## 可复现检查

在仓库根目录执行 README 中的三个验证命令。单元测试用临时目录验证检查器的成功和失败路径，不修改工作区项目，也不需要网络。

检查器支持 UTF-8 Markdown、围栏外的内联文件链接、名称及单行 description 的 Skill 元数据。它不是完整 Markdown 或 YAML 解析器；不覆盖参考式链接、锚点、外部 URL、完整 YAML schema 或正文语义。新增依赖前优先评估这些范围是否真的需要扩大。

## 场景验收方法

在独立临时目录复制模板后，用实际 Agent 读取相应 Skill 完成下列任务，并检查产物而不是仅检查回答。不能把人工阅读脚本或模拟检查当作实际 Agent 使用通过。

1. 空项目：提出一个单文件工具需求，检查是否只问必要问题、是否避免无关目录。
2. 初始化完成：下一次小修复不应再次启动初始化，也不应生成无用总结。
3. 模块演进：只有新增独立职责或局部约束时才创建对应 README 或 AGENTS。
4. 文档变化：改变一个配置或接口，旧说明应原位修订；没有长期知识差异时允许零文档修改。
5. 表达取舍：精简说明后保留条件、责任和失败后果，不按字数机械裁剪。
6. 治理审查：只要求审查时不修改；已授权修正时验证具体问题而非全仓扩张。

以上是验收方法，不表示所有宿主已完成实测。实际执行记录以该版本交付说明为准；CI 只运行结构检查与检查器单元测试。后续业务项目必须另建业务验证，模板测试不能代表其正确性。
