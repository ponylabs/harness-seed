# 维护 Agent Notes

Agent Note 保存代码、测试和当前文档不能充分解释的“为什么”和“放弃了什么”。先查已有拥有者：更新原记录可以满足要求，机械修改和局部 UI 调整不要求建记录。文档分类入口见 [文档约定](../../../docs/AGENTS.md)。

## 位置与格式

路径固定为 `.agents/notes/{状态}/{类别}/yyyy-mm-dd-topic-title.md`；日期是首次提出日期，不随修改或移动变化。主题用英文小写 kebab-case，正文中文。状态为 proposed、implemented、rejected；archived 是单独的冻结历史目录，只接收已实现记录。类别封闭为：feature（新能力）、bug-fix（修复）、simplification（移除复杂度）、architecture（已交付源码结构）、process（围绕代码的工具与流程）、testing（测试基础与策略）。不要新增含混的 refactor 类。

新建需要的目录即可，不预建全部组合。第一次创建 Notes 时可建立 `.agents/notes/README.md` 和 `AGENTS.md`，只解释该项目实际记录的入口并链接本 Skill，不复制整套状态规范。不得创建集中 `INDEX.md`。引用其他记录用相对 Markdown 链接，不用裸编号。

记录前三行：`# Agent Note: 中文主题`、空行、`Status: proposed`。状态与路径一致；拒绝写 `Status: rejected — 一句话原因`。标题和状态字段保留上游稳定标识，正文标题采用以下统一中文名称，不混用同义词：

- proposed：`## 问题`、`## 提案`、`## 考虑过的替代方案`、`## 验收条件`、`## 风险`。
- implemented：`## 问题`、`## 决策`、`## 考虑过的替代方案`、`## 后果`。
- rejected：保留 proposed 正文骨架，移动时仅在 Status 加拒绝理由并冻结正文；不得改写成已经实施。

问题脱离解法也能成立，替代是真正可行的选择，验收可观察。必要技术章节可插入，但不要用章节海洋或任务时间线替代决策。

## 状态与日常更新

未实现或部分实现留在 proposed；已经作出的实际决策从 implemented 开始。完成后移动到 implemented，更新状态并将“提案”改为现在时的“决策”；验收条件与风险归入“后果”或已验证的测试章节，移除尚未交付的计划语气。保留首次日期并修复所有活跃入链。放弃提案移到 rejected，不直接归档 proposed。

implemented 同次追踪已交付事实的路径、名称、默认值和结构变化；不能把旧决策改成相反结论。重大新决定创建新记录并互链。跨会话未完成方案的目标、已确认决定、下一步和验证缺口保留在 proposed 的相应内容里，新会话先核实现状，不重做已确认初始化。

## 每篇新记录的取代检查

搜索活跃树里相同机制或决定，判断没有、部分或完整取代。部分取代保留两篇、互链并更新仍有效事实。完整合并只有在新拥有者保留全部独有理由、替代、后果、必需验证及命名覆盖缺口后才可删除旧记录，并修复入链；不能以 Git 历史是唯一副本为理由删掉知识。删除仍需当前授权。

功能移除记录只有确认生产实现、配置、schema、持久化/传输格式、迁移和兼容路径、当前文档及支持性测试均不再保留该功能时，才能完整接管旧记录。接管需保留原动机、为何不再值得、替代移除方案、放弃的能力、重新引入条件及完整移除证据；只移除一种入口、默认值或实现属于部分取代。

## 归档与删除

按未来决策价值，不按年龄、字数或数量配额。仍解释所有权、安全、兼容、持久语义、负向保证或重引入条件的记录保留活跃。已完成且理由不再指导后续、仍有历史价值的 implemented 移至 `archived/{类别}/原文件名`；保留 `Status: implemented`，下一行加入 `Archived: YYYY-MM-DD`。只改状态附加行和迁移必须的入口，不现代化正文。

归档后冻结：不得编辑、翻译、格式化、移动或删除，不当作当前行为权威；出链保留历史语境，活跃入链仍须有效。细碎机械记录可在授权范围内删除；rejected 仅在仍防止有吸引力的真实错误时保留。归档不是垃圾箱，也不保留每次会话日志。

## 验证与交付

核对类别、首次日期、状态、必要章节、相对入链和取代关系；运行项目实际检查。当前结构脚本只检查路径、日期与链接，不校验正文语义、Status 一致性或冻结哈希，人工审查不可省略。不移植上游双语三件套和封存脚本，也不声称已有防篡改门禁。报告保留、更新、拒绝、归档或删除列表及理由；有争议先保留并指出。
